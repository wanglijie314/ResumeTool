    词表管理

    “页面文本 → 标准字段”的全局词表，跨站点生效。教学浮层里点「就是这个字段」会记一条 教学；下面手动登记的是 别名（同义词，例：页面叫“本科院校”，字段选“毕业院校”， 之后两种叫法都能识别）。

    站点忽略

    只在对应站点生效的“不再提示/忽略”记录（教学浮层里选「本站忽略」产生）。

    运行日志

    每次页面内容脚本启动 = 一个会话（按时间命名）。保留最近 20 个会话， 事件超过 1 天自动清理；日志同步打印到浏览器控制台。

    AI 设置 （可选 · 填写后识别/解析更准确）

    未启用 · 使用内置算法识别与解析

    填写 API Key 后，AI 会在两处增强：

    • 页面字段识别：「扫描并填写」弹窗对未识别字段给出 AI 建议（仅发送控件的 标签/提示词/形态，不含你填写的值；接受后才生效并记住）。
    • 简历解析：上传简历时，规则解析遗漏/疑似错误的部分会自动交给 AI 补齐（会将该部分与简历上下文发送给你填写的模型服务商），结果以可编辑草稿进入预览。

    不填写 = 完全使用内置算法填写与解析，不发送任何内容。接口需兼容 /chat/completions + JSON 输出（智谱即此格式）。API Key 只存本机。

    建议先用智谱低成本档试跑；把 model 换成你想用的免费/低成本型号即可，无需改其它配置。 想完全关闭 AI，清空 API Key 保存即可。

    关于与隐私

    • 所有数据（档案副本、学习规则、设置、日志）仅保存在本机浏览器的 chrome.storage.local。默认不会上传任何服务器。
    • 仅当你在「AI 设置」填写了 API Key：页面字段识别会发送控件的 标签/提示词/形态 给该模型服务商；上传简历时，规则解析遗漏/疑似错误的部分会连同简历上下文发送给该服务商。不填写 API Key 则不发送任何内容。
    • 敏感字段（如身份证号 🔒）填写前由你在弹窗中确认内容后才会写入页面。
    • 内容脚本只在你访问的页面内读取表单控件描述，不收集浏览历史。
